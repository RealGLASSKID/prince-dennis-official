# Prince Dennis Official

Build a premium official personal website for GLASSKID (Prince Dennis) from Lagos, Nigeria.

This is not a portfolio. The website should feel like my personal digital home — authentic, elegant, futuristic, and centered around who I am, my story, personality, journey, interests, thoughts, and life.

Create these pages:
Home, About Me, My Journey, Blog, Gallery, and Contact.

The Blog should allow me to publish personal stories, thoughts, updates, experiences, announcements, and anything about me. Include individual blog post pages.

Use a dark luxury design with black, glassmorphism, subtle purple (#8B5CF6) accents, cinematic imagery, smooth animations, and modern typography. Keep it minimal but visually impressive, responsive, and personal rather than corporate.
